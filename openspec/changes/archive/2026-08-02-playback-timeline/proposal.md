## Why
当前播放 HUD 仅有一条进度条 + 照片名/时间/速度控件，用户在播放长跨度（如多年度）轨迹时无法直观看到当前播放时间在整段区间里的相对位置，也无法在不拖动进度条的情况下按时间段快速跳转。需要为播放态加一条**横向时间刻度线**：覆盖播放区间的年/月刻度、背景透明、与进度条互相同步、可在刻度线上点选/拖动跳转到对应位置。

## What Changes
- 新增播放时间刻度线：在 `#playHud` 上方铺满横向宽度的玻璃/透明带（左右让出两侧 dock 宽度），含年/月刻度（年为主、月为次，两端强制标注起始年/结束年，例如播放 2022→2026 时最左标签为 `2022`、最右为 `2026`），短区间额外显示月份标签
- 播放过程中实时显示**当前位置游标线**（与 HUD 进度条互相同步），播放停止/未播放时整条隐藏
- **双向同步**：拖动 HUD 进度条 → 时间刻度线游标跟随移动；在时间刻度线上点按或拖动 → 跳转到对应索引，进度条与播放状态同步更新
- 背景透明度跟随底图主题：标准底图浅色玻璃 + 近黑前景，卫星底图深色玻璃 + 近白前景（避免与卫星影像混淆）；左右缩进到两侧 dock 按钮列之外，不与左下/右下操作图标重叠
- **新增「缩略图」开关**（默认开）：关闭后播放不叠加缩略图 marker，整个画面走 dot 模式（视感：轨迹点闪动播放），并按三态颜色区分：区间外橙、区间内未播蓝、区间内已播绿、当前活跃亮橙放大；点击点位照旧触发查看器展示缩略图
- **新增「区间外点位」开关**（默认关）：关闭时播放区间外的照片点位从地图隐藏，只留区间内点位；勾选则以橙色降级显示（原有行为）

## Impact
- **代码**：
  - `app.js`：`startPlay` 末尾根据 `player.list` 起止时间调用 `renderTimeline()` 构建并渲染时间刻度，`positionTimelineAboveHud()` 动态定位；`tickPlay` 与 `#hudSeek` 的 input/change 回调同步游标位置；新增 `#htHit` 的 pointerdown/move/up 拖动跳转处理；`stopPlay` 隐藏时间刻度线。新增 `player.showThumb` / `player.showOutRange` / `player.playedHashes` / `player.lastIdx`，`renderVisible()` / `applyPlayStyles()` / `clearPlayStyles()` 按开关与三态颜色（`#ff9500` 区间外橙、`#2b6cff` 未播蓝、`#34c759` 已播绿、`#ff6b35` 当前活跃亮橙）染色，`tickPlay` 区分顺序前进 / 跳转前进两种已播集合维护策略
  - `index.html`：在 `#playHud` 之后新增 `#hudTimeline` 容器结构与刻度/标签/游标样式；在播放设置弹窗新增「缩略图」与「区间外点位」两个复选框
- **依赖**：无新依赖；复用既有 `fmtTime`/`toLocalInput` 与 `Date`/`getTime` 计算
- **行为**：
  - 播放过程中 HUD 上方出现一条铺满横向宽度的时间刻度线，刻度基于播放区间自动计算年/月边界，两端强制标注起始年/结束年，进度条与刻度线游标实时双向同步，可在刻度线上点按/拖动跳转到对应位置；停止播放整条隐藏
  - 默认在点位上叠加缩略图；关闭「缩略图」开关后走圆点三态播放（已播绿、未播蓝、当前活跃放大亮橙）
  - 默认隐藏区间外点位；勾选「区间外点位」后以橙色降级显示
  - 跳转（进度条 / 时间刻度）后已播集合按新位置重建，所有点位颜色同步刷新
- **风险**：
  - 在很长的播放区间（>5 年）下刻度可能过密 —— 通过始终绘制年/月刻度 + 短区间（≤180 天）才显示月份标签缓解
  - 极短区间（<1 个月）月刻度数量少 —— 两端强制年份标签保证可读
  - 关闭缩略图后用户可能丢失对照片内容的直观感知 —— 已播/未播/当前三态颜色提供进度反馈，点击点位照旧触发查看器展示缩略图
