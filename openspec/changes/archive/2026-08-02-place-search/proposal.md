## Why
照片地图缺少"按地名找位置"的能力：用户想快速定位到某个城市、区县或 5A 景区时，只能手动平移缩放，效率低；对海外或小众地点更无从下手。同时，纯在线搜索在无网络或网络受限时完全不可用，而国内主要行政区划与知名景区这类高频地点本可离线命中。需在**不引入 API Key** 的前提下，提供即时、可部分离线的地点搜索，让"搜地名→飞到该点"一步完成。

## What Changes
- 新增左上角玻璃风**地点搜索框**：输入防抖约 350ms、≥2 字符触发搜索，含加载圈、Esc 清空、失焦延迟收起
- **本地数据集优先**：引入中国省/市/区三级行政区划（3257 条）与 5A 景区（358 条）数据文件（GCJ-02 坐标，免 Key），按名称/完整路径子串匹配、最多返回 8 条，命中即时展示、无需联网
- **在线地理编码降级**：本地无命中或想搜更全时，调用 OSM Nominatim（免 Key、CORS 开放）；OSM 超时/网络错误/限流（429）时自动降级到镜像地球（api.mirror-earth.com），并带约 60 秒冷却的智能切换，避免反复苦等
- **合并结果展示与选择跳转**：本地结果在前、在线结果在后（带"在线搜索"分隔），点击任一结果地图飞到该地点并按类型选择缩放级别；国内在线结果自动做 WGS84→GCJ02 纠偏，本地结果（GCJ-02）直接复用坐标
- **数据文件缺失降级**：file:// 下若数据文件未加载，本地数据集为空，仅走在线搜索，不报错、不阻断

## Impact
- **代码**：`app.js`（initMap 末调用搜索初始化；新增 `initSearchBox` 及本地检索 / 在线降级 / 合并渲染逻辑）、`index.html`（新增 `#searchBox` 玻璃风搜索框结构与样式，并在脚本区引入 `vendor/china-places.js`、`vendor/scenic-5a.js`）
- **依赖**：新增两个本地数据文件 `vendor/china-places.js`（省市区，来源 AreaCity-JsSpider-StatsGov，MIT）、`vendor/scenic-5a.js`（5A 景区，来源文旅部官方名录 + apihz.cn 公开记录）；在线搜索运行时依赖 OSM Nominatim 与镜像地球（均免 Key、联网）
- **行为**：地图左上角出现地点搜索框；输入即搜，国内行政区划/景区即时返回，无网络时仍可搜国内主要地点；在线搜索可覆盖全球地名
- **风险**：OSM/镜像地球为远端服务，网络不稳定时在线结果可能延迟或失败，此时仍保留本地结果；海外在线结果经 `inChina` 判定是否做 GCJ02 纠偏
- **坐标系**：本地数据集为 GCJ-02，与高德瓦片一致无需纠偏；在线结果多为 WGS84，国内结果需逆纠偏以对齐高德瓦片
