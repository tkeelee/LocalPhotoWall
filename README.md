# 照片地图 · 时空轨迹

单机版照片地图网页应用 —— 把带 GPS 信息的照片按拍摄地点铺在地图上，按时间顺序回放轨迹。**无需任何 API Key、无需安装依赖、数据全部留在本地**，双击即用。

## 功能特性

### 地图与底图
- 高德公开瓦片（标准 / 卫星两种模式切换），免注册免 Key
- **国内 / 海外底图自动切换**：以地图中心点判定 —— 国内用高德（GCJ02），海外用 OSM 标准图 / Esri 卫星影像 + 地名边界层（WGS84），跨区平移无感切换并轻提示
- 照片点位 WGS84 → GCJ02 自动纠偏，国内精准落图；海外点位不偏移，与 WGS84 瓦片天然对齐
- 左上角**地点搜索框**：输入即搜，本地省市区 + 5A 景区数据集优先命中（免 Key、可离线），无结果时自动联机 OSM / 镜像地球地理编码补全；选中即飞到该地点，国内结果自动纠偏
- 点位缩略图随地图缩放按比例变化
- 鼠标悬停（PC）/ 点按缩略图居中弹出大图，不遮挡背景地图；点击空白处或 Esc 关闭
- 大图卡片右上角支持**编辑**（仅文件名 / 路径）与**删除**（二次确认，立即从数据库删除不可恢复）
- 原图缺失时缩略图等比放大 5 倍兜底显示，不报错

### 照片导入
- PC 端按目录递归导入（含全部子目录），也可直接多选文件；手机形态下走相册多选
- 支持 JPEG / PNG / WebP / HEIC / HEIF / TIFF，按文件头嗅探，不依赖扩展名
- 自研 ExifLite 解析 EXIF：GPS 坐标、拍摄时间、尺寸、海拔（含 HEIC 的 ISO BMFF 盒结构）
- SHA-256 哈希去重（`file://` 下自动降级为内置混合哈希），重复导入自动跳过
- **无 GPS 的照片不入库**，仅计入提示明细（可用「手动补录」为其补坐标）
- 浏览器无法解码的格式（如 Chrome 下的 HEIC）自动生成带文件名的占位缩略图，GPS 点位照常上图
- 导入完成后屏幕居中提示完整明细，示例：
  > 共导入 100 张，40 张重复（根据哈希值判断），50 张未提取到经纬度，实际导入 10 张。

### 数据存储
- 基于 sql.js 的本地 SQLite，主库 `photos.db` 与网页同目录
- **即时落盘**：导入、增量加载、补录、删除、编辑完成后自动写回 `photos.db`，无需手动保存
- **增量加载数据**（菜单二选一）：
  - 「增量加载」：选择已有 `.db` 文件追加合并，哈希冲突时**后载入为准**
  - 「初始空间」：选择目录读取其下 `photos.db`，不存在则自动创建空库
- **备份数据库**：仅在点击备份按钮时复制当前主库为 `photos_YYMMDDHHMMSS_bak.db`；常规写操作直接覆盖主库、不自动备份
- 首次操作时锁定项目目录并记忆（File System Access API + localStorage），后续加载/保存默认到该目录

### 时空轨迹播放
- 选择起止时间，按拍摄顺序依次高亮照片；弹窗内**实时显示当前范围内的照片数**
- 自动**记忆上次播放区间**，下次打开自动带入
- 当前照片抖动并放大 2 倍，地图只平移居中、绝不自动缩放
- 0.5× / 1× / 2× / 4× / 8× 速度，**播放中可随时调速**
- HUD 进度条**可拖动跳转**到任意位置，拖动时实时预览照片名与时间
- 区间内点位保持蓝色，区间外点位降级为橙色（缩略图模式为橙框半透明）
- 快捷键：空格 = 暂停/继续，Esc = 停止播放

### 数据库直接管理
- 预览当前内存库（只读保护），或任选其他 `.db` 文件预览/编辑；自动识别并保护当前正在加载的库
- 双击行内编辑「文件名 / 照片路径」，其余字段只读；底部详情卡展示完整行信息
- 按拍摄时间段筛选（默认全部），分页展示（PC 每页 10 条 / 手机每页 5 条）
- **导出 CSV**（含 BOM，Excel 直接打开不乱码）
- **导入 CSV 全量覆盖**：按哈希匹配执行增 / 改 / 删（事务保护），完成后在页面上方提示「共 X 条 → 新增 Y · 更新 Z · 删除 N」

### 手动补录
- 为无 GPS 照片补坐标：进入补录模式后**长按地图选点**，经纬度自动回填（GCJ02 → WGS84 迭代逆解）
- 拍摄时间以照片 EXIF 为准（存在则锁定输入框），否则手填
- 保存即写库并即时上图；**哈希重复禁止保存**
- 播放中禁止补录，暂停 / 停止后可补录；补录点位不在播放区间时自动套用区间外样式

### 界面与性能
- 左下竖向工具栏 + 右下控件栈，纯图标 + 悬停提示；PC / 手机双形态自适应（右下角一键切换）
- 提示信息屏幕居中显示，默认持续 5 秒
- 低缩放级别用 **Canvas 圆点**（单画布渲染，万级点位不卡），高缩放用缩略图 + **视口裁剪** + rAF 分批创建
- 数据库分批加载（每批 200 行让出主线程），大数据集不卡死 UI
- 未保存更改时关闭页面会触发浏览器拦截提醒

## 技术栈

| 模块   | 技术                                                     | 说明                              |
| ------ | -------------------------------------------------------- | --------------------------------- |
| 地图   | [Leaflet](https://leafletjs.com/) 1.9                    | 本地 vendor，无 CDN               |
| 瓦片源 | 高德公开瓦片（国内）/ OSM + Esri World Imagery（海外）   | 均免注册免 Key                    |
| 存储   | [sql.js](https://sql.js.org/) 1.10                       | SQLite 编译到 WASM，file:// 降级 asm.js |
| EXIF   | 自研 ExifLite（exif.js）                                 | 零依赖，支持 JPEG/PNG/WebP/HEIC/TIFF |
| 前端   | 原生 HTML + CSS + JS                                     | 无构建工具、无框架                |

## 快速开始

### 方式一：启动脚本（推荐）

**Mac**：双击 `启动-Mac.command`
**Windows**：双击 `启动-Windows.bat`

脚本从 8623 端口起自动顺延占用端口，启动本地 HTTP 服务并自动打开浏览器，同目录的 `photos.db` 会被自动加载。

> 手机访问：电脑和手机连同一 WiFi，用手机浏览器打开终端提示的局域网地址。

### 方式二：直接双击 HTML

双击 `index.html` 即可使用（sql.js 自动降级 asm.js 运行），但有以下限制：
- 无法自动加载同目录的 `photos.db`（需通过「增量加载数据」按钮手动载入）
- 加载 / 保存数据库时首次需选择目录授权

### 左下角工具栏（从上到下）

| 图标 | 功能           | 说明                                                                                 |

| 🗄️   | 增量加载数据   | 「增量加载」选 `.db` 追加合并（后载入为准）；「初始空间」选目录读取 / 自动创建 `photos.db` |
| 💾   | 备份数据库     | 复制当前主库为 `photos_YYMMDDHHMMSS_bak.db`，不覆盖原文件                             |
| ▶️   | 预览播放       | 选择时间范围与速度，按拍摄顺序播放轨迹                                                |
| ▦    | 数据库直接管理 | 预览 / 行内编辑 / 筛选 / 分页 / 导出 CSV / 导入 CSV 覆盖                              |
| ⊕    | 手动补录       | 长按地图选点，为无 GPS 照片补坐标；播放中禁用                                         |

### 左上角搜索框

- 输入 ≥2 个字符即开始搜索（防抖 350ms），本地省市区与 5A 景区按名称 / 路径匹配优先返回，命中即时展示、无需联网
- 本地无匹配或想搜更全时，自动联机 OSM Nominatim / 镜像地球地理编码补全（覆盖全球地名）；主服务不可达时自动降级，网络受限时仍保留本地结果
- 选中结果地图直接飞到该地点并按类型缩放到合适级别；国内在线结果自动做 WGS84→GCJ02 纠偏
- 数据来自 `vendor/china-places.js`（省市区三级）与 `vendor/scenic-5a.js`（5A 景区），均为 GCJ-02 坐标；file:// 下若数据文件缺失则仅走在线搜索

### 右下角控件

- **+ / −**：地图缩放
- **图层图标**：标准 / 卫星地图切换（国内、海外底图共用该状态）
- **手机/PC 图标**：切换设备形态布局

### 首次加载 / 保存

由于浏览器安全限制，首次操作时会弹出目录选择器：
1. 选择 `index.html` 所在目录
2. 授权读写权限
3. 之后所有加载 / 保存操作默认到该目录，不再询问

> 导入、增量加载、补录、删除、编辑完成后会**自动写入** `photos.db`，无需手动保存。「备份数据库」按钮仅用于生成带时间戳的备份副本。未加载数据库时点击「导入照片」或「手动补录」会自动引导选择初始空间。

## 浏览器兼容性

| 浏览器             | 支持情况                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------- |
| Chrome / Edge 86+  | **完整功能**（File System Access API 直写项目目录）                                                |
| Firefox            | 浏览、播放、自动加载 `photos.db` 可用；**不支持直写文件**，导入 / 补录 / 编辑保存等写操作会被拦截，建议仅作查看 |
| Safari 14+         | 同 Firefox：查看与播放可用，写操作受 File System Access API 缺失限制                               |

> 简言之：**数据管理用电脑端 Chrome / Edge，手机适合同一 WiFi 下看地图和回放轨迹。**

## 常见问题

**Q：打开后看不到照片？**
A：双击打开（file://）时无法自动读取 `photos.db`，请用启动脚本打开，或手动点击「增量加载数据」导入 db 文件。

**Q：保存时为什么让我选目录？**
A：浏览器安全限制，JS 无法直接访问文件系统。首次授权后，后续操作默认到该目录。建议选择 `index.html` 所在目录。

**Q：导入的照片原图找不到了？**
A：导入时只存了缩略图和元数据。若原图路径失效，查看大图时会自动用缩略图放大 5 倍显示，不会报错。

**Q：为什么有的照片没有出现在地图上？**
A：没有 GPS 信息的照片不会入库也不会上图，只在提示明细中计入"未提取到经纬度"数量。需要上图的话，用左下角「手动补录」长按地图为其补坐标即可。

**Q：支持哪些图片格式？**
A：JPEG / PNG / HEIC / HEIF / WebP / TIFF。Chrome 下 HEIC 无法解码的会显示占位缩略图，GPS 点位照常上图。

**Q：海外照片点位有地图底图吗？**
A：有。地图中心移到海外时会自动切换为 OSM 标准图 / Esri 卫星影像（WGS84，点位无需纠偏）。海外瓦片服务器在境外，首次加载较慢属正常现象。

**Q：离线瓦片下载功能在哪？**
A：该功能已实现但**默认禁用**（代码与 UI 均注释保留）。重新启用步骤见 `app.js` 中「离线瓦片下载功能」注释块。

**Q：手机端能导入照片吗？**
A：当前版本不行。导入要求浏览器支持目录直写（File System Access API），手机浏览器均不支持，前置校验会拦截导入操作。请在电脑端导入后，手机同 WiFi 访问查看。

**Q：数据库文件很大怎么办？**
A：缩略图以 JPEG Data URL 形式存库，几千张照片约几十 MB 属正常。可用「数据库直接管理 → 导出 CSV」留档，或把历史库移入 `bak/` 目录归档。
