# 照片地图 · 时空轨迹

单机版照片地图网页应用 — 把带 GPS 信息的照片按拍摄地点铺在地图上，按时间顺序回放轨迹。**无需任何 API Key**，双击即用。

## 功能特性

### 地图
- 高德公开瓦片地图（标准 / 卫星两种模式切换）
- 随缩放级别自动调整缩略图大小
- 鼠标悬停缩略图弹出高清原图，不遮挡背景地图

### 照片管理
- **导入照片**：PC 端按目录递归导入（含子目录）；手机端从相册多选
- 自动读取 EXIF（GPS 坐标、拍摄时间、尺寸等）
- 按哈希值去重，重复导入自动跳过
- **无 GPS 的照片不入库**，仅计数提示
- 缩略图自动生成并入库
- 原图缺失时缩略图等比例放大 5 倍显示，不报错
- 导入完成后居中提示完整明细，示例：
  > 共导入 100 张，40 张重复（根据哈希值判断），50 张未提取到经纬度，实际导入 10 张。

### 数据存储
- 基于 sql.js 本地 SQLite，数据文件 `photos.db` 与网页同目录
- **增量加载数据**：合并多个 `.db` 文件，按哈希自动去重
- **保存数据**：自动备份旧文件（`photos_YYYYMMDDHHmmss.db`），新建 `photos.db`
- 首次操作时锁定项目目录，后续加载/保存默认到该目录

### 时空轨迹播放
- 选择起止时间，按拍摄顺序依次高亮照片
- 缩略图抖动放大 2 倍，平移视野（不自动缩放）
- 支持 0.5× / 1× / 2× / 4× / 8× 播放速度
- 播放弹窗时间范围变化时**实时显示当前范围内的照片数**

### 界面交互
- 左下角**竖向**工具栏（与右下角控件栈对称），纯图标 + 悬停提示
- 提示信息**屏幕居中**显示，持续 8 秒
- PC / 手机双形态自适应，右下角一键切换
- 手机端布局优化，左下角工具栏保持紧凑竖向，不撑满宽度
- 支持同一 WiFi 下手机访问

## 技术栈

| 模块     | 技术                                   | 说明                |
| -------- | -------------------------------------- | ------------------- |
| 地图     | [Leaflet](https://leafletjs.com/) 1.x | 本地 vendor，无 CDN |
| 瓦片源   | 高德公开瓦片                           | 无需注册 API Key    |
| 存储     | [sql.js](https://sql.js.org/) 1.10    | SQLite 编译到 WASM  |
| EXIF     | exif-js 2.3                            | 读取照片元数据      |
| 前端     | 原生 HTML + CSS + JS                   | 无构建工具、无框架  |

## 快速开始

### 方式一：启动脚本（推荐）

**Mac**：双击 `启动-Mac.command`

**Windows**：双击 `启动-Windows.bat`

脚本会启动本地 HTTP 服务器并自动打开浏览器，同目录的 `photos.db` 会被自动加载。

> 手机访问：电脑和手机连同一 WiFi，用手机浏览器打开终端提示的地址。

### 方式二：直接双击 HTML

双击 `index.html` 即可使用，功能完整，但有以下限制：
- 无法自动加载同目录的 `photos.db`（需手动通过"加载数据"按钮导入）
- 加载/保存数据库时首次需选择目录授权

## 使用说明

### 左下角工具栏（从上到下）

| 图标 | 功能       | 说明                                                         |
| ---- | ---------- | ------------------------------------------------------------ |
| 📥   | 导入照片   | PC 选目录递归导入；手机从相册多选；自动读 EXIF 并去重        |
| 🗄️   | 增量加载数据 | 选择 `.db` 文件合并到当前数据；按哈希自动去重                |
| 💾   | 保存数据   | 写入项目目录 `photos.db`；旧文件自动备份为 `photos_时间戳.db` |
| ▶️   | 预览播放   | 选择时间范围与速度，按拍摄顺序播放轨迹                       |

### 右下角控件

- **+ / −**：地图缩放
- **手机/PC 图标**：切换设备形态布局
- **图层图标**：标准 / 卫星地图切换

### 首次加载/保存

由于浏览器安全限制，首次使用"加载"或"保存"时会弹出目录选择器：
1. 选择 `index.html` 所在目录
2. 授权读写权限
3. 之后所有加载/保存操作默认到该目录，不再询问

## 数据库结构

`photos` 表字段：

| 字段         | 类型    | 说明                          |
| ------------ | ------- | ----------------------------- |
| id           | INTEGER | 主键自增                      |
| hash         | TEXT    | 照片哈希（去重依据），UNIQUE  |
| name         | TEXT    | 文件名                        |
| path         | TEXT    | 原始路径                      |
| taken_at     | TEXT    | 拍摄时间字符串                |
| taken_ts     | INTEGER | 拍摄时间戳（毫秒）            |
| lat / lng    | REAL    | GPS 纬度 / 经度（WGS84）      |
| alt          | REAL    | GPS 海拔                      |
| width        | INTEGER | 照片宽度                      |
| height       | INTEGER | 照片高度                      |
| size         | INTEGER | 文件大小（字节）             |
| thumb        | TEXT    | 缩略图 Data URL               |
| thumb_w / thumb_h | INTEGER | 缩略图尺寸              |
| imported_at  | TEXT    | 导入时间                      |

## 常见问题

**Q：打开后看不到照片？**
A：双击打开时无法自动读取 `photos.db`，请用启动脚本打开，或手动点击"加载数据"导入 db 文件。

**Q：保存时为什么让我选目录？**
A：浏览器安全限制，JS 无法直接访问文件系统。首次授权后，后续操作默认到该目录。建议选择 `index.html` 所在目录。

**Q：导入的照片原图找不到了？**
A：导入时只存了缩略图和元数据。若原图路径失效，查看大图时会自动用缩略图放大 5 倍显示，不会报错。

**Q：为什么有的照片没有出现在地图上？**
A：没有 GPS 信息的照片不会入库也不会上图，只在提示明细中计入"未提取到经纬度"数量。如需查看这些照片，请用其他工具先补全 EXIF GPS 信息再导入。

**Q：导入/加载的提示信息看不清？**
A：提示已改为屏幕居中显示，持续 8 秒。包含完整明细：总数、重复数、无 GPS 数、实际导入数。

**Q：支持哪些图片格式？**
A：JPEG / PNG / HEIC / HEIF / WebP / TIFF。Chrome 下 HEIC 无法解码的会显示占位缩略图，GPS 点位照常上图。
